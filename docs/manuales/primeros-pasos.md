# Primeros pasos

## Acceder al sistema

1. Abrir el navegador (Chrome o Firefox recomendado)
2. Ingresar a la URL del sistema:
   - **Producción:** http://35.198.12.188
   - **Desarrollo:** http://34.151.246.79
3. Iniciar sesión con tu usuario y contraseña

!!! note "Primera vez"
    Si es la primera vez que ingresás, solicitá tus credenciales al administrador (Julio Giraudi o Carlos Bendayan).

## Pantalla de login

- Ingresá tu **usuario** y **contraseña**
- Hacé clic en **Ingresar**
- Si las credenciales son correctas, serás redirigido al Dashboard

## Navegación general

El sistema tiene un menú lateral izquierdo con acceso a todos los módulos disponibles:

| Sección | Descripción |
|---------|-------------|
| **Dashboard** | Vista general del sistema |
| **Artículos** | Catálogo de productos y repuestos |
| **Clientes** | Directorio de clientes |
| **Proveedores** | Directorio de proveedores |
| **Stock** | Inventario por sucursal |
| **Usuarios** | Gestión de usuarios *(solo ADMIN)* |

## Módulos disponibles hoy

### Clientes

### Proveedores

## Cerrar sesión

Para cerrar sesión, hacé clic en tu nombre de usuario o en el ícono de salida en la esquina superior derecha del sistema.
