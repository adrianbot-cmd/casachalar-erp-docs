# Primeros pasos

## Acceder al sistema

1. Abrir el navegador (Chrome o Firefox recomendado)
2. Ingresar a la URL del sistema:
   - **Producción:** https://one-erp.casachalar.com
   - **Desarrollo:** http://34.151.246.79
3. Iniciar sesión con tu usuario y contraseña

!!! note "Primera vez"
    Si es la primera vez que ingresás, solicitá tus credenciales al administrador del sistema.

## Pantalla de login

- Ingresá tu **usuario** y **contraseña**
- Hacé clic en **Ingresar**
- Serás redirigido al Dashboard

!!! tip "Sesión expirada"
    Si el sistema muestra "Error al cargar" en alguna pantalla, es posible que tu sesión haya expirado. Ingresá a la URL de login y volvé a iniciar sesión. El sistema también te redirige automáticamente.

## Navegación general

El sistema tiene un menú lateral izquierdo con acceso a todos los módulos:

| Sección | Descripción |
|---------|-------------|
| **Dashboard** | Vista general del sistema |
| **Artículos** | Catálogo de productos y repuestos |
| **Stock** | Inventario por sucursal |
| **Catálogos** | Categorías y marcas de artículos |
| **Listas de Precio** | Precios por lista y canal |
| **Ventas** | Cotizaciones, Pedidos, Facturas y Recibos |
| **Proveedores** | Directorio de proveedores |
| **Clientes** | Directorio de clientes |
| **Usuarios** | Gestión de usuarios *(solo ADMIN)* |

## Módulos disponibles

### Artículos
- Ver el catálogo completo de artículos
- Crear, modificar y dar de baja artículos
- Ver [manual de Artículos](../modulos/articulos.md)

### Clientes
- Ver, crear y modificar clientes
- Configurar descuentos por defecto del cliente
- Ver [manual de Clientes](../modulos/clientes.md)

### Proveedores
- Ver, crear y modificar proveedores
- Ver [manual de Proveedores](../modulos/proveedores.md)

### Stock
- Consultar el stock actual por sucursal
- Registrar entradas, salidas y ajustes de inventario
- Ver [manual de Stock](../modulos/stock.md)

### Ventas
El módulo de Ventas sigue un flujo integrado:

```
Cotización → Pedido → Factura → Recibo de Cobro
```

Ver el **[Manual de Ventas](ventas.md)** para instrucciones completas.

- [Cotizaciones](../modulos/cotizaciones.md) — Presupuestos al cliente
- [Pedidos](../modulos/pedidos.md) — Confirmación del pedido
- [Facturas](../modulos/facturas.md) — Documentación de la venta
- [Recibos de Cobro](../modulos/recibos-cobro.md) — Registro de pagos

### Usuarios *(solo ADMIN y SUPER_ADMIN)*
- Crear y gestionar usuarios del sistema
- Asignar roles y permisos
- Ver [manual de Usuarios](../modulos/usuarios.md)

## Cerrar sesión

Hacé clic en tu nombre de usuario en la esquina superior derecha del sistema y seleccioná **Cerrar sesión**.
